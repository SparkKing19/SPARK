SPARK MUSIC ADD-ON (for the existing SparkCore project)

FILES TO ADD
1. handlers/music.js
2. handlers/musicPlayer.js
3. utils/musicUtils.js

The existing index.js already auto-loads every .js file in handlers/, so do not replace index.js for this add-on.

INSTALL PACKAGE
Run in the project terminal / Railway build environment:
  npm install lavalink-client

ENVIRONMENT VARIABLES (Railway > SparkCore service > Variables)
  CLIENT_ID=your Discord application/bot ID
  LAVALINK_HOST=your Lavalink host (hostname only, no http://)
  LAVALINK_PORT=2333 (replace with the actual port)
  LAVALINK_PASSWORD=your Lavalink password
  LAVALINK_SECURE=false (set true only when the node uses TLS/WSS)
  LAVALINK_ID=spark-main (optional)
  MUSIC_BOT_NAME=SPARK Music (optional)
  MUSIC_SEARCH_PLATFORM=ytsearch (optional; depends on the configured Lavalink source plugin)

IMPORTANT
- Lavalink is a separate Java service and must be running and reachable from the bot.
- A Lavalink server alone does not guarantee any particular music source works. Install/configure a source plugin that is compatible with your Lavalink version and the provider's current rules.
- This add-on uses the existing Discord client and its GuildVoiceStates intent. The supplied index.js already includes GuildVoiceStates and automatically loads handlers.
- Prefix commands require the Message Content intent to be enabled in the Discord Developer Portal. The supplied index.js already requests GatewayIntentBits.MessageContent.
- Prefix is % (not slash commands).
- Commands: %join, %leave / %left, %play <song or URL>, %pause, %resume, %skip, %stop, %queue, %nowplaying / %np, %volume 1-100, %loop off|song|queue, %shuffle, %remove <number>, %clear, %seek 1:30, %help.
- Player buttons: previous, pause/resume, skip, stop, loop, volume, queue, refresh.
- Existing SparkCore handlers and slash commands are not replaced.
